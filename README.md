# Курсовий проєкт: Структури даних та алгоритми під час керування проєктами

## Загальна інформація
* Дисципліна: Алгоритми та структури даних
* Тема: Структури даних та алгоритми під час керування проєктами. Порівняння алгоритмів сортування з пірамідальним як базовим
* Мова розробки: C# (.NET 10 / .NET 8)
* Середовище розробки: JetBrains Rider / Visual Studio

---
## Інструкція зі збирання та запуску проєкту

### Запуск через середовище розробки (Rider / Visual Studio):
1. Відкрити файл рішення: `ProjectManagementSorting.sln`.
2. Дочекатися завершення індексації та відновлення залежностей (NuGet/SDK).
3. У верхній панелі вибрати конфігурацію запуску: **`ProjectManagement.ConsoleApp`**.
4. Натиснути кнопку **Run** (зелений трикутник) або гарячі клавіші:
  * JetBrains Rider: `Shift + F10`
  * Visual Studio: `F5` або `Ctrl + F5`

### Запуск через термінал (CLI):
```bash
# Перевірка та компіляція всього рішення:
dotnet build

# Запуск головного проєкту програми:
dotnet run --project ProjectManagement.ConsoleApp
```

## Персональний розподіл обов'язків

### Зона відповідальності: Дмитро
* Папка `ProjectManagement.Core/Models`:
    * `TaskItem.cs` — клас задачі з полями та реалізацією інтерфейсу `IComparable<TaskItem>`.
    * `Project.cs` — логіка збереження та маніпуляції списком завдань.
* Папка `ProjectManagement.Core/Generators`:
    * `TaskDataGenerator.cs` — створення тестових наборів задач із різними математичними розподілами.
* Папка `ProjectManagement.Algorithms/Heap`:
    * `BinaryHeap.cs` — двійкова купа з операціями вставки, вилучення кореня та просіювання (`siftUp`, `siftDown`).
    * `HeapSort.cs` — базовий алгоритм пірамідального сортування з лічильниками порівнянь та обмінів.
* Папка `ProjectManagement.ConsoleApp`:
    * `Program.cs` — текстове меню взаємодії та демонстрація пріоритетної черги задач.
* Пояснювальна записка (звіт):
    * Вступ, аналіз предметної області (керування проєктами).
    * Розділ 1: Теорія двійкової купи, аналіз операцій відновлення властивостей купи.
    * Розділ 2: Архітектурне проєктування системи (UML-діаграма класів).

### Зона відповідальності: Олександр
* Папка `ProjectManagement.Algorithms/Common`:
    * `ISortingAlgorithm.cs` — інтерфейс сортування з методом `Sort()`.
    * `SortStatistics.cs` — контейнер для збереження часу, кількості порівнянь та кількості перестановок.
* Папка `ProjectManagement.Algorithms/Comparators`:
    * `QuickSort.cs` — швидке сортування з лічильниками кроків.
    * `MergeSort.cs` — сортування злиттям з лічильниками кроків.
    * `InsertionSort.cs` — сортування вставками з лічильниками кроків.
* Папка `ProjectManagement.ConsoleApp` (модуль вимірювань):
    * `Program.cs` — автоматизований запуск бенчмарків (вибірки N від 100 до 100 000).
    * Експорт отриманих результатів тестування у файл `benchmark_results.csv`.
* Пояснювальна записка (звіт):
    * Розділ 1 (частина 2): Теоретичний опис QuickSort, MergeSort, InsertionSort (складність, стабільність).
    * Розділ 3: Опис програмної реалізації алгоритмів порівняння та логіки вимірювання.
    * Розділ 4: Експериментальна частина — зведені таблиці, графіки ефективності, висновки.
